# Security Policy

## Supported versions

Only the latest version on the `main` branch receives fixes.

## What this mod does

aurora-chat only changes how the Claude Code desktop app draws messages and the status bar. It makes no network requests, reads no files, and runs no processes. It keeps turn statistics (counts, model name, current folder name) in the session's state only.

## Report a vulnerability

Do **not** open a public issue for a security problem.

Report it privately through GitHub: open the [Security tab](https://github.com/Fanaperana/aurora-chat/security) of this repository and click **Report a vulnerability**.

Include:

- A description of the problem and its effect
- Steps to reproduce it
- Your Claude Code version (`claude --version`)

You will get an answer as soon as possible. When the fix is released, you will be credited unless you ask not to be.
